# 定时器

---

### 一、设置定时器

代码执行从上往下，定时器（需要时间的操作），异步执行。

1、<code>setInterval(fn, time)</code> &nbsp;&nbsp;&nbsp;&nbsp;每隔多少毫秒执行fn代码

* fn 要执行的函数
* time 毫秒数

2、<code>setTimeout(fn, time)</code> &nbsp;&nbsp;&nbsp;&nbsp;延迟多少毫秒执行fn代码（**只执行一次**）

* fn 要执行的函数
* time 毫秒数

### 二、清除定时器

1、<code>clearInterval(intervalId)</code>

```js
let num = 0, intervalId = null;
let max = 10;
let incrementNumber = function() {
    num++;
    // 如果达到最大值，则取消所有未执行的任务
    if (num == max) {
        clearInterval(intervalId);
        alert("Done");
    }
}
intervalId = setInterval(incrementNumber, 500);
```

2、<code>clearTimeout(timeoutId)</code>

```js
let timeoutId = setTimeout(() => alert("Hello world!"), 1000);
clearTimeout(timeoutId); 
```

!> 注意：当用事件开启定时器前，记得清除上一次的定时器（尽量将定时器名字声明为函数外）
